# Карта адресов

Общая карта России для командной работы. Каждый участник вводит имя, ищет любой адрес, берёт его в работу и отмечает «изучил». Остальные видят всё в реальном времени: кто онлайн, кто какой адрес сейчас смотрит и какие адреса заняты.

## Запуск

Нужен Node.js 18 или новее.

```
npm install
npm start
```

Откройте http://localhost:3000. Чтобы играть всей командой, запустите приложение на сервере с адресом в интернете (VPS, Render, Railway, Fly.io) и дайте участникам ссылку. На хостинге включите HTTPS: тогда WebSocket автоматически работает по `wss`.

Данные о занятых адресах лежат в файле `data.json` рядом с сервером и переживают перезапуск. На хостингах с временным диском подключите постоянный том и укажите путь в `DATA_FILE`.

## Как это работает

- Карта: Leaflet и данные OpenStreetMap. В них есть города, улицы и дома по всей России, данные обновляются постоянно.
- Поиск: Nominatim (поиск по OpenStreetMap). Запросы идут через сервер с очередью и кэшем, чтобы не превышать лимит 1 запрос в секунду.
- Клик по дому: приблизьте карту (масштаб 16 и ближе) и нажмите на здание, адрес определится сам.
- Один адрес берёт в работу только один человек. Чужой адрес нельзя ни взять, ни отметить. Свой можно отпустить, отметить «изучил» или вернуть в работу.
- Оранжевые точки на карте: в работе. Зелёные: изучено. Цветные метки с именем: кто что сейчас смотрит.

## Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт сервера | `3000` |
| `DATA_FILE` | где хранить состояние | `./data.json` |
| `CONTACT` | ваш email для заголовка User-Agent (требование Nominatim) | `admin@example.com` |
| `NOMINATIM_URL` | адрес своего сервера поиска | публичный nominatim.openstreetmap.org |
| `TILE_URL` | шаблон плиток карты | плитки OpenStreetMap |
| `TILE_ATTRIBUTION` | подпись авторства под картой | OpenStreetMap |

## Важно про нагрузку

Публичные серверы OpenStreetMap (плитки и поиск) рассчитаны на небольшое использование. Для компании в десятки человек этого обычно хватает. Если участников много, возьмите коммерческий провайдер плиток (например, MapTiler или Stadia) через `TILE_URL` и поднимите свой Nominatim или используйте платный геокодер через `NOMINATIM_URL`. Не забудьте указать `CONTACT`.

Google Maps не используется: ему нужен платный API-ключ, а условия не разрешают копировать его данные в собственную карту.

## Проверка

```
npm test
```

Тест запускает сервер и проверяет логику двух участников: конфликт при «взять в работу», «изучил», «отпустить», смену имени и сохранение на диск.
